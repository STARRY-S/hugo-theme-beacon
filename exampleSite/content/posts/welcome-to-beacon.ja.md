Beacon は、速度と読みやすさのために作られたミニマルなブログテーマです。この記事では
タイポグラフィと各機能を紹介し、あなたのコンテンツがどのように見えるかを確認できます。

## 主な機能

Beacon は軽量なエディトリアルレイアウトに、モダンな深いチャコール配色、くっきりとした
タイポグラフィ、そして控えめなモーションを組み合わせ、落ち着いた集中できる読書体験を
提供します。次の機能を備えています：

- ライト / ダーク / 自動 のカラーモード（選択を記憶）
- 細い区切り線で整理したエディトリアルな記事一覧トップページ
- 読了時間、文字数、タグ、パンくずリスト
- 目次、コードコピーボタン、共有リンク
- SEO、OpenGraph、Twitter カードのメタデータを標準搭載

## タイポグラフィ

まずは引用で雰囲気を：

> シンプルさは究極の洗練である。

そして順序付きリスト：

1. Markdown で記事を書く
2. `content/posts/` に置く
3. `hugo server` を実行してプレビュー

### コードブロック

インラインの `code` はこのように表示されます。フェンス付きコードブロックは、
ホバーするとコピーボタンが現れます：

```go
package main

import "fmt"

func main() {
    fmt.Println("Hello, Beacon!")
}
```

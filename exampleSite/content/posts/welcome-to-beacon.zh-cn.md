Beacon 是一款为速度与可读性打造的极简博客主题。这篇文章展示了排版与各项功能，
让你预览自己的内容会呈现出怎样的效果。

## 有哪些功能

Beacon 将双栏卡片布局与现代深灰配色、清晰的排版以及细腻的动效结合在一起，
带来平静而专注的阅读体验。它内置了：

- 浅色 / 深色 / 自动 三种配色模式，并会记住你的选择
- 简洁双栏布局的卡片式文章列表首页
- 阅读时间、字数、标签与面包屑导航
- 目录、代码复制按钮与分享链接
- 开箱即用的 SEO、OpenGraph 与 Twitter 卡片元数据

## 排版

先用一段引用定个基调：

> 简约是终极的复杂。

再来一个有序列表：

1. 用 Markdown 撰写文章
2. 放入 `content/posts/` 目录
3. 运行 `hugo server` 预览

### 代码块

行内 `code` 是这样的。围栏代码块在鼠标悬停时会显示复制按钮：

```go
package main

import "fmt"

func main() {
    fmt.Println("Hello, Beacon!")
}
```

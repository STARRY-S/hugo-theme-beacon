Beacon is a minimal blog theme built for speed and readability. This post shows
off the typography and features so you can see how your content will look.

## What's inside

Beacon pairs a focused editorial layout with a modern deep-charcoal palette,
crisp typography, and gentle motion — a calm, focused reading experience. It
ships with:

- Light / dark / auto color modes with a persisted toggle
- A separated post list with an optional profile sidebar
- Reading time, word count, tags, and breadcrumbs
- Table of contents, code-copy buttons, and share links
- SEO, OpenGraph, and Twitter card metadata out of the box

## Typography

Here's a blockquote to set the tone:

> Simplicity is the ultimate sophistication.

And an ordered list:

1. Write your post in Markdown
2. Drop it in `content/posts/`
3. Run `hugo server` and preview

### Code blocks

Inline `code` looks like this. Fenced blocks get a copy button on hover:

```go
package main

import "fmt"

func main() {
    fmt.Println("Hello, Beacon!")
}
```
